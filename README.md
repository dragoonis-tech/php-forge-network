# ByteHire PHP Network

Create a new candidate landing page for ByteHire (https://bytehire.io), specifically targeting the PHP developer and engineering community.

The page will live within the existing ByteHire website:

bytehire.io

IMPORTANT: USE THE EXISTING BYTEHIRE DESIGN

First analyse the existing ByteHire website and its current visual identity.

The new PHP landing page should look and feel like it has always been part of bytehire.io.

Use the existing website as the design system and reference for:

Header and navigation

Logo treatment

Typography

Font sizes and weights

Brand colours

Background colours

Buttons and CTAs

Border radius

Cards and containers

Section spacing

Page width

Shadows

Icons

Footer

Responsive/mobile behaviour

Overall visual language

Do not redesign or reinterpret the ByteHire brand.

Do not create a generic SaaS landing page.

Do not introduce a new colour palette, typography system or visual identity.

The objective is to create a new page within the existing ByteHire website, not a standalone microsite.

PAGE OBJECTIVE

This is a candidate acquisition landing page, not a client sales page.

The audience is:

PHP developers, software engineers, senior/principal engineers, architects and technical leaders.

The primary goal is:

Get PHP professionals to join the ByteHire PHP Network.

The page should make the visitor feel that ByteHire understands technical people and understands the PHP community.

The central message is:

Your PHP experience is more than your CV.

ByteHire looks beyond technologies and keywords to understand what someone has actually built, solved and delivered.

DESIGN DIRECTION

Keep the page:

Modern

Technical

Premium

Community-focused

Human

Highly scannable

Visually interesting

Concise

Avoid large blocks of text.

The supplied copy is intentionally short. Allow typography, spacing, visual hierarchy and imagery/graphics to give the page impact rather than adding additional paragraphs.

Important statements such as:

“Your PHP experience is more than your CV.”

“We look beyond the CV.”

“It's what you've built, solved and delivered.”

should receive strong visual emphasis.

PAGE FLOW

Use the supplied copy to create approximately this structure:

1. Hero

Large headline:

Your PHP experience is more than your CV.

Supporting sentence.

Strong primary CTA:

Join the PHP Network

The hero should immediately communicate that this is specifically for PHP professionals.

2. We Look Beyond the CV

Make this a strong visual section rather than a traditional text section.

Emphasise:

It's what you've built, solved and delivered.

Consider visual elements that contrast CV keywords with real engineering experience.

Do not overcomplicate it.

3. People Who Understand PHP

Communicate that candidates are being represented by technically credible people rather than generic recruiters.

Headline:

Be represented by people who understand PHP.

Strong supporting statement:

We speak your language.

4. You Don't Need to Be Looking

Reduce the perceived commitment required to join.

Visually communicate the three potential states:

Actively searching

Open to something interesting

Happy where I am

All three should lead naturally towards joining the network.

5. PHP Community / Paul Dragoonis

Create a credibility section around Paul Dragoonis.

Use the supplied wording exactly.

Highlight the key credibility points visually:

PHP & open-source contributor
PHP-FIG member
PSR author
Public speaker
PHP conference organiser
20+ years in the PHP community

This should establish why ByteHire genuinely understands PHP rather than appearing to be a recruitment company targeting PHP developers.

Keep this section concise.

6. Final CTA

Finish with a visually strong conversion section.

Headline:

Be part of the network.

Supporting line:

Developers. Engineers. Architects. Technical leaders.

Primary CTA:

Join the ByteHire PHP Network

CTA BEHAVIOUR

Use Join the PHP Network consistently as the main CTA.

The CTA should appear:

In the hero

At appropriate points while scrolling

In the final conversion section

The page should have one obvious primary action rather than multiple competing actions.

JOIN FORM

The CTA should lead to a simple candidate registration form.

Keep friction low.

Suggested fields:

First name

Last name

Email

Location

LinkedIn profile

Current role

Primary PHP experience

Symfony / Laravel / Other

CV upload – optional

Current situation

For current situation, offer:

Actively looking

Open to opportunities

Not looking, but keep me in the network

Do not make CV upload mandatory.

This is important because the messaging of the page is that your experience is more than your CV.

COPY

Use the PHP landing-page copy supplied separately.

Do not substantially rewrite, expand or replace the supplied copy.

You may make very small formatting changes where necessary for the design, but preserve the wording and messaging.

Do not generate long paragraphs to fill space.

If a section needs more visual weight, solve that through design, not additional copy.

RESPONSIVE DESIGN

The page must work particularly well on mobile.

Maintain:

Strong headline hierarchy

Short sections

Large touch-friendly CTAs

Clear form controls

Generous spacing

Fast scanning

The mobile version should retain the visual character of the existing ByteHire website.

FINAL REQUIREMENT

Before designing the new page, establish the visual patterns used by bytehire.io.

Then build the PHP landing page using those patterns.

The finished result should feel like:

“ByteHire created a page specifically for its PHP community.”

Not:

“An AI created a PHP-themed landing page for ByteHire.”
